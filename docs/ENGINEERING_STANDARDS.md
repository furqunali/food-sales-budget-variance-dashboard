# Engineering Standards

This dashboard separates presentation from deterministic business calculations.

- Keep variance calculations reusable and testable.
- Treat zero-budget cases explicitly.
- Add regression tests for every calculation change.
- Do not commit private customer/source data, credentials, or generated secrets.
- Preserve genuine Git history; project history and pull-request activity must reflect real work.

The repository is being improved for production-quality AI/data-training review without manufacturing LOC, files, pull requests, or historical dates.
